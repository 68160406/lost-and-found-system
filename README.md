# ระบบแจ้งของหายและพบของในมหาวิทยาลัย (University Lost and Found System)

## 📌 1. Pain Point & Problem Statement
- เมื่อนิสิตหรือบุคลากรทำของหาย มักไม่รู้ว่าต้องไปตามหาที่ไหน และไม่รู้ว่ามีใครเก็บได้หรือไม่
- คนที่เก็บของได้ ต้องการส่งคืนเจ้าของ แต่ไม่รู้ว่าของชิ้นนั้นเป็นของใคร หรือจะติดต่อเจ้าของได้อย่างไร
- การโพสต์ตามหาในกลุ่มโซเชียลมีเดีย (เช่น Facebook/LINE Group) โพสต์มักจะถูกดันเลื่อนหายไปอย่างรวดเร็ว ทำให้ค้นหายากและตกหล่น

## 👥 2. Target Users & Proposed Solution
- **กลุ่มผู้ใช้งาน (Target Users):** นิสิต, อาจารย์, บุคลากรในมหาวิทยาลัย และเจ้าหน้าที่ดูแลอาคาร
- **แนวทางการแก้ไข (Proposed Solution):**
  - พัฒนาศูนย์กลาง Web Application สำหรับแจ้งของหายและประกาศพบสิ่งของ
  - **สำหรับผู้เก็บของได้:** สามารถถ่ายรูปสิ่งของ ระบุสถานที่ที่พบ และลงทะเบียนประกาศแจ้งพบลงในเว็บ พร้อมทิ้งข้อมูลติดต่อ เพื่อตามหาเจ้าของ
  - **สำหรับผู้ทำของหาย:** สามารถโพสต์รายละเอียด รูปถ่ายสิ่งของ และช่องทางติดต่อไว้ในระบบ เผื่อมีผู้พบเห็นมาติดต่อคืน
  - มีระบบค้นหา กรองหมวดหมู่/สถานที่ และระบบอัปเดตสถานะเมื่อมีการส่งคืนเรียบร้อยแล้ว

## 📋 3. Scope & Key Features
- **ระบบสมาชิกและการสิทธิ์ใช้งาน (Authentication):**
  - เข้าสู่ระบบ (Login) / ออกจากระบบ (Logout) เพื่อระบุตัวตนผู้โพสต์
- **ระบบประกาศแจ้งพบสิ่งของ (Found Items CRUD):**
  - **Create:** อัปโหลดรูปภาพสิ่งของที่เก็บได้, ระบุชื่อสิ่งของ, หมวดหมู่, วันเวลา, สถานที่ที่พบ และ **ช่องทางติดต่อ (เบอร์โทร / LINE ID)**
  - **Read:** แสดงรายการของที่พบทั้งหมด พร้อมระบบค้นหา (Search & Filter)
- **ระบบประกาศแจ้งของหาย (Lost Items CRUD):**
  - **Create:** โพสต์แจ้งของหาย พร้อมแนบรูปภาพ (ถ้ามี), ระบุสถานที่ที่คาดว่าทำตกหาย และ **ช่องทางติดต่อ**
  - **Read/Update/Delete:** จัดการ ลบ หรือแก้ไขโพสต์ของตนเองได้
- **ระบบติดต่อและรับสิ่งของคืน (Contact & Claiming System):**
  - **Privacy & Security:** ข้อมูลติดต่อ (เบอร์โทร/LINE ID) จะแสดงผลเฉพาะผู้ใช้งานที่เข้าสู่ระบบ (Login) แล้วเท่านั้น เพื่อความปลอดภัยของผู้โพสต์
  - **Status Management:** เจ้าของหรือผู้พบสามารถกดอัปเดตสถานะเป็น "ส่งคืนเรียบร้อยแล้ว" (Returned) ได้เมื่อเจอกันและส่งมอบของกันสำเร็จ

## 🗄 4. Draft ER Diagram
โครงสร้างตารางข้อมูลเบื้องต้นประกอบด้วย 3 ตารางหลัก:
1. **Users** (id, username, password, name, phone, email, created_at)
2. **Categories** (id, category_name)
3. **Items** (id, user_id, category_id, title, description, image_path, location, contact_info, type ['lost'/'found'], status ['active'/'returned'], created_at)
